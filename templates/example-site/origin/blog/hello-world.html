This is the first post on the fixture blog. It exists so the dom_extract tool has something to chew on.

The Worker fetches this page server-side, runs HTMLRewriter against it with the selector configured in the TOML, and returns the readable text region as the tool result.

If you are reading this in your browser through the proxy, the Worker also injected a bootstrapper that registered the site's tools with your WebMCP-aware browser.
