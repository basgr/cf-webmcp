About WebMCP

WebMCP is a way for websites to expose structured tools that AI agents can call. There are two runtimes behind the same name, and they reach different agents.

  • The W3C draft (webmachinelearning/webmcp): a browser API at document.modelContext (older builds expose the deprecated navigator.modelContext alias). Used by browser-native agents (Chrome, Cloudflare Kitesurf, Cloudflare Browser Run lab sessions). No pairing needed; tools register automatically when the page loads. Chrome ships WebMCP to users through an origin trial (from Chrome 149) on sites that send a trial token; without one, WebMCP is behind chrome://flags/#enable-webmcp-testing.
  • The jasonjmcghee library (jasonjmcghee/WebMCP): a localhost websocket bridge for desktop MCP clients (Claude Desktop, Cursor, Claude Code, Windsurf). Requires the bridge program running on your computer and a pairing token.

This site uses cf-webmcp to expose both surfaces from a single config.
